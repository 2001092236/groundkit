Как это работает

Четыре шага. Модель не ходит в интернет сама: поиск и проверка ссылок делаются кодом, поэтому одинаково работают с любой бесплатной моделью.

1. ПоискSearXNG → DuckDuckGo → Jina по очереди. Результаты фильтруются по белому списку доменов.
2. КонтекстСкачиваем текст страниц, вырезаем инструкции-инъекции, нумеруем источники.
3. МодельGemini Flash → Groq → … Исчерпался лимит — берём следующую, бесплатно.
4. ПроверкаКаждый URL и номер [n] в ответе сверяется с выдачей. Чужое — вырезается и показывается в отчёте.
