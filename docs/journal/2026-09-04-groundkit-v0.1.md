# 2026-09-04 — groundkit 0.1: библиотека «бесплатные LLM + поиск + проверка ссылок»

## Что просили

Сделать из заготовки в папке `groundkit` настоящий GitHub-проект: библиотеку для бесплатного использования LLM и поискового движка (плюс Claude Code как LLM), протестировать, красиво оформить и дать возможность задавать вопросы прямо на странице.

## Что сделано простыми словами

- **Библиотека работает целиком.** Вопрос → поиск по разрешённым сайтам → скачивание текста страниц → бесплатная модель → программная проверка каждой ссылки и номера источника в ответе. Если модель что-то придумала — это вырезается и показывается в отчёте.
- **Модели переключаются сами.** Задаётся цепочка (Gemini → Groq → …); когда у одной кончился дневной лимит, берётся следующая. Библиотека сама видит, какие ключи есть в `.env`.
- **Поиск с резервом.** SearXNG (свой, безлимитный) → DuckDuckGo → Jina → Exa → Brave. Работает даже без единого ключа.
- **Claude Code как чистая модель.** Для собственных экспериментов можно указать `claude-cli`: библиотека запускает установленный Claude Code без инструментов и файлов, только как модель. В веб-демо это выключено по умолчанию — использовать подписку как бэкенд для чужих людей запрещено правилами Anthropic.
- **Переформулировка вопроса.** Разговорный вопрос («соседи шумят, как их наказать?») модель сначала превращает в поисковый запрос («нарушение тишины во дворе жилого дома ответственность»), иначе поиск по юридическим сайтам ничего не находит. Если и так пусто — ищем исходный текст.
- **Командная строка**: `groundkit ask`, `groundkit search`, `groundkit providers`, `groundkit serve`.
- **Веб-демо**: страница, где можно задать вопрос, выбрать пресет доменов (право, медицина, финансы, Python) и увидеть источники, ответ с зелёными подтверждёнными сносками и отчёт проверки (сколько ссылок вырезано, какая модель ответила, были ли переключения).
- **Docker-стенд**: SearXNG + API + HTTPS одной командой.
- **Тесты**: 44 юнит-теста без сети (парсинг всех провайдеров, фильтр доменов, резервирование, проверка ссылок, инъекции, API, лимиты) и 5 живых тестов.

## Что показали живые тесты

Реальный запуск «DuckDuckGo → Claude CLI → проверка» на вопросе о форме договора аренды здания: найдено 5 источников только с consultant.ru и garant.ru, ответ по ст. 651 ГК РФ со ссылками [1]–[5], указана дата редакции (24.06.2025), ни одной выдуманной ссылки. Время: поиск 4 с, страницы 2 с, модель 20 с.

## Ключи и лимиты (дополнение вечером 04.09)

Эрнест прислал ключи. Проверка живыми вызовами:

| Провайдер | Итог |
|---|---|
| Groq | Работает с сервера (из РФ API закрыт: «Access denied»). Старой Llama 3.3 70B в каталоге больше нет, взяты Qwen 3.8 27B и GPT-OSS 120B. Лимит 1000 запросов/день и 8K токенов/мин |
| Cloudflare Workers AI | Работает, Llama 3.3 70B за ~1.5 с |
| OpenRouter | Ключ валиден (free tier). Из 18 free-моделей отвечают Gemma 4 26B/31B; часть моделей временно перегружена общим пулом |
| Mistral | 429 с `x-ratelimit-limit-req-minute: 0` — на аккаунте не включён бесплатный план Experiment |
| Cerebras | 402 Payment Required — план не активирован |
| Qwen (DashScope) | Ключ принимается международным эндпоинтом, но любая модель отвечает «AccessDenied.Unpurchased» — сервис Model Studio не активирован |
| Exa, Jina | Поиск работает |

Добавлен учёт лимитов: журнал вызовов, `groundkit usage`, `GET /api/usage`, панель на странице демо. Контекст для модели ограничен 12 000 символами, чтобы влезать в 8K токенов/мин у Groq.

## Как проверить самому

1. `pip install -e ".[dev]"` и `pytest -q` — должно быть зелёным.
2. `GROUNDKIT_LIVE=1 pytest -m live -s` — живой поиск и Claude CLI.
3. `groundkit providers` — покажет, какие ключи видны.
4. `scripts/dev.sh` и открыть http://127.0.0.1:8765 — демо с Claude CLI в роли модели.

## Что осталось / что может сломаться

- Для публичного демо нужны бесплатные ключи Gemini и Groq (регистрация на aistudio.google.com и console.groq.com). Без них демо показывает найденные источники и просит ключ.
- Лимиты бесплатных провайдеров меняются; цифры в README — на 4 сентября 2026.
- SearXNG может временно терять движки при агрессивном опросе; в цепочке есть резерв DDG/Jina.
